# Rule of thumb: cut anything that fills the pool with product release notes
# or general science. Hyperscaler blogs are the worst offenders. The model's
# own web searches catch the genuinely big announcements anyway.


# --- Ranked aggregators, the useful kind of "trending" -------------------
# These rank by attention rather than by publication time, which is what a
# trending list is supposed to do. Techmeme is editorially ordered by
# importance. The Reddit and Lobsters feeds rank by community votes.
#
# Note on X and Twitter trend sites: deliberately absent. Those boards rank by
# spike velocity, which structurally favours entertainment and sport. Enterprise
# AI is a steady conversation and can never out-spike a football match, so the
# list is entertainment noise every single day. Aggregators that scrape those
# boards inherit the same problem.
